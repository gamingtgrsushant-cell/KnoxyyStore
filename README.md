# Knoxyy Store

Free Fire PC / Emulator Hub store page: Sensi, Optimization, Bat Files, Debloater, Emulator, Registry, Tweaks.

Single-file static website (no build step, no dependencies).

## Live site
After enabling GitHub Pages: `https://<your-username>.github.io/<repo-name>/`

## Edit prices / info
Open `index.html` and find the block marked `EDIT HERE`:
- `DISCORD` = your Discord invite link
- `ITEMS` = name, price, info and feature list of each pack
- `BUNDLE_PRICE` = full bundle price
